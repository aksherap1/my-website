Everything I've built...

Diving into digital logic completely changed how I look at hardware—there’s nothing cooler than watching 0s and 1s track in real time and seeing D flip-flops keep everything in sync on a clock edge. Lately, I've taken that hands-on energy into robotics and drones: dialing in CAD models, designing for DFM/DFA, and collecting flight data in the field.

Interactive Household Robotics (Lamp & Alarm Clock)↗

June 2026 – Present

I wanted to build desktop robots with real personality, so I designed a custom 6-DOF robotic alarm clock and lamp in Onshape. The clock uses daisy-chained micro servos to move its head and ears, waking you up with expressive gestures before the audio alarm even sounds. I also routed a custom 2-layer PCB in KiCad with an ESP32-S3 and built-in DC-DC power regulation to drive all the motors cleanly. Everything was optimized for rapid 3D printing and easy hand assembly using standard hardware and heat-set inserts.

Autonomous Drone Warehouse Surveyor↗

June 2026 – Present

This project focuses on building an autonomous multicopter system tailored for indoor warehouse inspection and inventory tracking. I modeled the custom drone airframe and dedicated camera mounts in SolidWorks, keeping the layout compact for tight spaces. After converting the CAD assembly into URDF and USD formats, I imported it into NVIDIA Isaac Sim to configure the physics, collision boundaries, and mass properties. From there, I scripted autonomous waypoint navigation and sensor feeds in Omniverse ActionGraph to test full flight paths in simulation before building hardware.

Osmosis Digital Logic Game

May 2026 – June 2026

For this project, I built a real-time digital game in VHDL that simulates molecular osmosis across a semi-permeable membrane. The system tracks multiple moving particles on a screen at the same time using synchronous finite state machines and sequential D flip-flop register arrays. I also wrote custom video display driver logic by defining exact horizontal and vertical timing constraints, sync pulses, and pixel generation windows. This made sure the graphics and real-time color sorting rendered smoothly on the display without any visual glitches.

Stop It Digital Logic Game

April 2026 – May 2026

I designed a fast-paced digital reaction game in Verilog and synthesized it onto a Xilinx FPGA. The game challenges players to stop a running counter at the exact moment two numbers add up to a pseudo-random target generated by an 8-bit Fibonacci LFSR. Under the hood, I built a synchronous 7-state Moore state machine using one-hot encoding to handle the gameplay flow, timer resets, and score updates. I also designed modular sub-circuits like a 16-bit LED score shifter and verified all the timing and state transitions using Vivado testbench simulations.

Air Mouse (ESP32 + MPU-6050)↗

Dec 2025 – Present

I am building a motion-controlled wireless mouse by interfacing an ESP32 with an MPU-6050 IMU over Bluetooth HID. I wrote the embedded firmware in C++ using the Arduino IDE to implement custom sensor filtering and calibration logic for precise cursor control. I have taken my breadboard prototype and routed a compact, multi-layer custom PCB in KiCad—focusing on hardware bring-up, proper trace routing for signal integrity, and surface-mount device (SMD) integration troubleshooting.

Music Visualizer — Wearable Audio-to-Haptic Device↗

Apr 2025 – Aug 2025

I built an assistive wearable device that transforms real-time audio frequencies into localized haptic vibration feedback. The system uses an Arduino 8-bit microcontroller to process incoming small-signal audio data. To keep up with real-time hardware constraints, I heavily optimized memory using Fixed FFT-8 algorithms with in-place computations, mapping frequency bins across a customized motor-driver circuit grid.

BattleBoats Project↗

May 2025 – Jun 2025

I developed a hardware-linked, multiplayer Battleship game on a 32-bit PIC32 MCU running MIPS architecture. The core logic uses embedded C and structural UART communication protocols for real-time board-to-board data exchange. I designed a rigid finite state machine (FSM) to cleanly separate the control plane (handshakes and turn syncing) from the live gameplay data plane, and implemented a secure, hashed key-based cryptographic negotiation protocol to prevent packet tampering or turn order manipulation.
